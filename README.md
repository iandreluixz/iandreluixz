## `04 // FEATURED_PROJECT`

### [api-campo-minado](https://github.com/iandreluixz/api-campo-minado)

API REST em Node.js para uma plataforma de apostas baseada no jogo Campo Minado. O jogador se cadastra, deposita saldo, inicia uma partida em um tabuleiro 5x5, revela posições e pode sacar o prêmio acumulado.

- Autenticação: cadastro, login e redefinição de senha
- Usuário: perfil, saldo e estatísticas pessoais (vitórias, derrotas, valores)
- Jogo: iniciar partida, revelar posição e sacar prêmio
- Regras de negócio: validação de senha, uma partida por vez, cálculo do prêmio
